## 📂 Repository Architecture

This repository is organized chronologically by week, separating daily concept drills from weekly labs and production-grade capstone projects:

* **`week-01-layout-flexbox/`** — Grid mechanics, Flexbox utilities, spacing scales, display toggles, and **Lab 1 (Dashboard Skeleton)**.
* **`week-02-core-components/`** — Typography, responsive tables, buttons, cards, list groups, and **Lab 2 (Pricing & Feature Matrix)**.
* **`week-03-navigation-js-ui/`** — Responsive navbars, Scrollspy, dropdowns, modals, accordions, and **Lab 3 (Interactive FAQ Portal)**.
* **`week-04-forms-dashboard-ui/`** — Grid forms, custom controls, validation states, carousels, and **Capstone 1 (Full SaaS Admin Dashboard)**.
* **`week-05-custom-sass-workflows/`** — Bootstrap `scss/` variable overrides, layout debugging drills, and **Capstone 2 (Custom E-Commerce Storefront)**.
* **`week-06-portfolio-launch/`** — Accessibility (`ARIA`), CSS optimization, and **Capstone 3 (High-Converting Startup Landing Page)**.

---

> 💡 **Previewing Projects:** Open any `.html` file inside the weekly folders using VS Code Live Server, or open the root `index.html` directory hub once GitHub Pages is deployed.
